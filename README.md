# Netflix Data Analysis

## Project Overview
This project explores a Netflix titles dataset using Python to understand the distribution of movies and TV shows, geographic content representation, release-year trends, content ratings, and popular genres.

The goal is to transform raw dataset information into meaningful findings through data cleaning, exploratory data analysis (EDA), and data visualisation.

## Objectives
- Clean and prepare the dataset for analysis.
- Compare the distribution of movies and TV shows.
- Identify countries with the highest number of titles.
- Explore trends in release years.
- Analyse content ratings and popular genres.
- Develop business insights and recommendations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Plotly
- JupyterLab

## Dataset
The dataset contains 8,790 Netflix titles and 10 columns, including title, content type, country, release year, rating, duration, and genre information.

## Key Findings
- Movies account for approximately 69.69% of the titles, while TV shows account for 30.31%.
- The United States has the highest number of titles with country information available, followed by India and the United Kingdom.
- The most frequently represented release years include 2018, 2017, and 2019.
- TV-MA and TV-14 are the most common content ratings.
- International Movies, Dramas, and Comedies are among the most frequently appearing genres.

## Project Workflow
1. Data cleaning and preparation.
2. Content type distribution analysis.
3. Country-wise content analysis.
4. Release-year trend analysis.
5. Rating and genre analysis.
6. Business insights and recommendations.

## Limitations
This analysis uses catalogue metadata. It does not measure actual viewership, audience engagement, revenue, or profitability. Genre counts represent genre appearances, so one title can contribute to multiple genres.

## Conclusion
This project demonstrates practical skills in data cleaning, exploratory data analysis, data visualisation, and communicating findings from a real-world-style dataset.
